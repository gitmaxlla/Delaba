# Делаба - Веб-приложение для планирования задач по учёбе

## Суть проекта

Приложение решает задачу сбора и отслеживания учебных заданий академических
групп из разных источников в едином месте.

**Администраторы** могут управлять набором академических групп (учебных
каналов), а также назначать новых модераторов (старост).

**Учебные каналы** представляют собой отдельные информационные пространства,
куда **модераторы** могут загружать задания по учёбe. Кроме того, они могут
приглашать новых пользователей в назначенный им администратором канал.

Загруженные задания при этом группируются по **предметам** (разделам).

Кроме этого, старосты могут публиковать **новости** в назначенный им канал в
текстовом формате.

## Как запустить?

> Для работы приложения требуются технологии Docker и Docker Compose.
> Предварительно убедитесь в том, что они поддерживаются и установлены на вашей
> системе.

### 1. Настройте файл окружения

**Вручную:**

- Скопируйте `.env.example` в корне проекта с новым названием `.env`
- Откройте новый файл и замените данные в угловых скобках (`"<Значение>"`) на
  собственные (`"МоёЗначение"`)
- Измените настройки по умолчанию при необходимости

**Через "сценарий-помощник":**

- Убедитесь, что у вас установлен python
- Запустите файл `dotenv-helper` из корня проекта через python
- Переопределите поля по умолчанию (если требуется) или добавьте свои значения
  (после чего в папке проекта будет сгенерирован итоговый `.env`)

### 2. Выберите режим работы

**Готовая система:**

- Выполните в терминале (находясь в корневой папке проекта) команду
  `sudo docker compose up`

**Разработка / тестирование:**

> Для работы в режиме разработки рекомендуется установить зависимости проекта
> локально через **uv** (./backend/) и **bun** (./frontend/) для корректной
> работы средств проверки кода.

- Установите [just](https://github.com/casey/just)
- Просмотрите список доступных команд через `just -l` и запустите новую с
  помощью `just <команда>`

> Увидеть запускаемые команды напрямую можно в файле `justfile`

## Процесс создания первого аккаунта администратора

### 1. Откройте веб-интерфейс

После запуска приложения интерфейс пользователя станет доступен по адресу:

- `<SERVER_HOSTNAME>` (`prod`)
- `127.0.0.1` (`dev`)

> В режиме разработки доступны привязки отдельных сервисов приложения к
> локальным портам. Ознакомиться с ними можно в файле
> docker-compose.override.yml.

### 2. Введите данные инициализации

Система при первом запуске автоматически выводит в консоль контейнера `backend`
первоначальный логин и пароль для создания аккаунта администратора:

```sh
Root login --> <...>
Root password --> <...>
```

Введите эти данные в соответствующие поля веб-интерфейса и задайте новый логин и
пароль администратора.
